# 印刷条件

色味の再現に使う印刷条件の構成と、各条件の再現の根拠

## 構成

印刷条件は次の 5 項目の組み合わせで決まります。

| 項目 | 選択肢 |
| --- | --- |
| 用途 | 名刺、ポスター、チラシ・フライヤー、冊子・同人誌 |
| 印刷方式 | オフセット印刷、オンデマンド印刷、大判インクジェット |
| 用紙 | コート紙、マットコート紙、上質紙、特殊紙 |
| PP 加工 | なし、グロス PP、マット PP |
| 印刷基準 | 日本、欧州、北米 |

用途は印刷方式と用紙の初期値を決めるためだけに使い、色の再現には影響しません。

## 用途ごとの初期値

| 用途 | 印刷方式 | 用紙 |
| --- | --- | --- |
| 名刺 | オンデマンド印刷 | マットコート紙 |
| ポスター | オフセット印刷 | コート紙 |
| チラシ・フライヤー | オフセット印刷 | コート紙 |
| 冊子・同人誌 | オフセット印刷 | 上質紙 |

## 印刷基準と内蔵プロファイル

| 地域 | コート紙、マットコート紙 | 上質紙、特殊紙 | 初期値となる表示言語 |
| --- | --- | --- | --- |
| 日本 | FOGRA39 で代用 | FOGRA47 で代用 | 日本語 |
| 欧州 | FOGRA39 | FOGRA47 | 英語 |
| 北米 | GRACoL 2013 | GRACoL 2013 UNC | なし |

地域は表示言語にかかわらず利用者が切り替えることができます。

Japan Color のプロファイルは再配布が許諾されていないため内蔵していません。\
日本の基準は近い条件の FOGRA のプロファイルで代用して目安であることを示し、\
正規のプロファイルの入手先と読み込みを案内します。

内蔵するプロファイルは再配布が許諾されたものに限り、無改変のまま `public/profiles` に置きます。\
各ファイルの権利者と条件は `public/profiles/NOTICE.txt` に記載しています。

## 再現の根拠

標準プロファイルがそのまま当てはまる条件は\
欧州または北米の基準で、オフセット印刷でコート紙または上質紙に PP 加工なしで印刷する場合です。

それ以外の条件は最も近い標準プロファイルを基に次の方法で再現し、\
画面上で目安であることを示します。

| 条件 | 再現方法 |
| --- | --- |
| 日本の基準 | FOGRA のプロファイルで代用 |
| オンデマンド印刷、大判インクジェット | オフセット基準のプロファイルに近似補正 |
| マットコート紙 | コート紙のプロファイルに近似補正 |
| 特殊紙 | 上質紙のプロファイルに近似補正を加え、紙色を反映 |
| PP 加工 | 近似補正 |

近似補正は彩度の倍率と最暗部の明度の増減で、標準データに基づかない独自の設定値です。（`src/lib/conditions.ts`）\
正確に確認する際は、印刷会社や機種の ICC プロファイルを読み込みます。

## 特殊紙

クラフト紙と生成りをプリセットとして用意し、\
加えて任意の紙色を指定することが可能です。

## 印刷プロファイルの選択

印刷プロファイルの出どころは次の 3 つです。

| 出どころ | 内容 |
| --- | --- |
| 条件から選択 | 印刷基準と用紙から決まる内蔵プロファイル |
| ファイルの指定 | CMYK 画像の埋め込みプロファイル、または PDF の OutputIntent |
| 読み込み | 利用者が読み込んだ CMYK の ICC プロファイル |

ファイルに指定がある場合は、それを初期値として使います。\
読み込んだプロファイルは端末に 1 件保存し、次回以降も選ぶことができます。

ファイルの指定または読み込んだプロファイルを使う間は、印刷方式・用紙・印刷基準の選択を無効にします。\
この場合に適用する近似補正は PP 加工だけです。
