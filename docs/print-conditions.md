# 印刷条件

色味の再現に使う印刷条件の構成と、各条件の再現の根拠

## 構成

印刷条件は次の 5 項目の組み合わせで決まります。

| 項目 | 選択肢 |
| --- | --- |
| 用途 | 名刺、ポスター、チラシ・フライヤー、冊子・同人誌 |
| 印刷方式 | オフセット印刷、オンデマンド印刷、大判インクジェット |
| 用紙 | コート紙、マットコート紙、上質紙、特殊紙 |
| PP 加工 | なし、グロス PP、マット PP |
| 印刷基準 | 日本、欧州、北米 |

用途は印刷方式と用紙の初期値を決めるために使い、色の再現には影響しません。\
立体表示では紙の大きさと厚さにも使います。

## 用途ごとの初期値

| 用途 | 印刷方式 | 用紙 |
| --- | --- | --- |
| 名刺 | オンデマンド印刷 | マットコート紙 |
| ポスター | オフセット印刷 | コート紙 |
| チラシ・フライヤー | オフセット印刷 | コート紙 |
| 冊子・同人誌 | オフセット印刷 | 上質紙 |

## 印刷基準と内蔵プロファイル

| 地域 | コート紙、マットコート紙 | 上質紙、特殊紙 | 初期値となる表示言語 |
| --- | --- | --- | --- |
| 日本 | FOGRA39 で代用 | FOGRA47 で代用 | 日本語 |
| 欧州 | FOGRA39 | FOGRA47 | 英語 |
| 北米 | GRACoL 2013 | GRACoL 2013 UNC | なし |

地域は表示言語にかかわらず利用者が切り替えることができます。

Japan Color のプロファイルは再配布が許諾されていないため内蔵していません。\
日本の基準は近い条件の FOGRA のプロファイルで代用して目安であることを示し、\
正規のプロファイルの入手先と読み込みを案内します。

内蔵するプロファイルは再配布が許諾されたものに限り、無改変のまま `public/profiles` に置きます。\
各ファイルの権利者と条件は `public/profiles/NOTICE.txt` に記載しています。

## 再現の根拠

標準の測色データがそのまま当てはまる条件は次の 2 つです。

- 欧州または北米の基準で、オフセット印刷でコート紙・マットコート紙・上質紙に PP 加工なしで印刷する場合
- 欧州の基準で、オフセット印刷でコート紙・マットコート紙に印刷して PP 加工をする場合

マットコート紙にはコート紙と同じプロファイルを使います。\
ISO 12647-2 は光沢のコート紙とマットコート紙に同じ基準値を定めていて、FOGRA39 は両方を対象とするためです。

それ以外の条件は最も近い標準プロファイルを基に次の方法で再現し、\
画面上で目安であることを示します。

| 条件 | 再現方法 |
| --- | --- |
| 日本の基準 | FOGRA のプロファイルで代用 |
| オンデマンド印刷、大判インクジェット | オフセット基準のプロファイルをそのまま使用 |
| 特殊紙 | 上質紙のプロファイルに紙色を反映 |
| 上記の 2 つ以外の条件での PP 加工 | コート紙で測った加工の前後の差を加算 |

正確に確認する際は、印刷会社や機種の ICC プロファイルを読み込みます。

### 日本の基準

Japan Color 2011（コート紙）の測色データ 1,588 色との差は、FOGRA39 が平均 ΔE00 1.7（95% が 3.7 以内）です。\
GRACoL 2013 は平均 2.2（95% が 4.3 以内）で、FOGRA39 のほうが近い条件です。

上質紙は、Japan Color 2001 のベタの黒（L\* 39）が FOGRA47（L\* 31）より浅く、暗い部分は実際より濃く表示されます。

### オンデマンド印刷と大判インクジェット

デジタル印刷機はオフセット印刷の基準値を目標に色を合わせるため、同じプロファイルを使います。\
基準値からの系統的なずれを示す標準データはなく、機種と用紙による差は許容差の範囲で残ります。\
Japan Color のデジタル印刷認証は、基準値との差を平均 ΔE00 2 以下、95% が 4 以下と定めています。

### PP 加工

ECI が公開している加工後のプロファイルを使います。\
FOGRA39 の条件で刷った印刷物に OPP フィルムを貼って測ったデータ（マットは FOGRA49、グロスは FOGRA50）に基づきます。

- 色の変化は平均で ΔE00 約 4 です。
- ベタの黒は加工前の L\* 16 から、グロスで 12、マットで 22 になります。
- フィルムを貼ると網点が太って見え、中間調はどちらも濃くなります。

分版は加工前の条件で作り、加工後の色は「印刷条件の測色値 + 加工後の測色値 − 加工前の測色値」で求めます。\
印刷条件が FOGRA39 の時は、加工後の測色値そのものになります。

## 特殊紙

特殊紙は風合いや手触りで選ぶ紙で、白や生成りのものが多く、クラフト紙のような色の付いた紙はその一部です。\
紙色は白・生成り・クラフトから選ぶか、任意の色を指定することが可能で、既定は白です。\
白は内蔵の上質紙プロファイル（FOGRA47）の紙白（L\* 95、a\* 0、b\* −2）と同じ色です。

## 印刷プロファイルの選択

印刷プロファイルの出どころは次の 3 つです。

| 出どころ | 内容 |
| --- | --- |
| 条件から選択 | 印刷基準と用紙から決まる内蔵プロファイル |
| ファイルの指定 | CMYK 画像の埋め込みプロファイル、または PDF の OutputIntent |
| 読み込み | 利用者が読み込んだ CMYK の ICC プロファイル |

ファイルに指定がある場合は、それを初期値として使います。\
読み込んだプロファイルは端末に 1 件保存し、次回以降も選ぶことができます。

ファイルの指定または読み込んだプロファイルを使う間は、用途・印刷方式・用紙・印刷基準の選択を表示しません。\
PP 加工はこの場合も反映し、目安であることを示します。\
立体表示の間は、つやを決めるために印刷方式と用紙を表示します。（色には影響しない）
