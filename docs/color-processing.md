# 色処理

入力データを印刷条件の色に変換し、画面に表示するまでの処理

すべての処理は端末内の Web Worker で行います。

## 元データと分版

入力から 2 種類の画素を用意します。

- 元データ：比較の基準となる画素と、その ICC プロファイル
- 分版：印刷条件の CMYK 値

| 入力 | 元データ | 分版 |
| --- | --- | --- |
| RGB 画像 | 元の RGB 値 | 元データを印刷プロファイルへ変換 |
| CMYK 画像 | 元の CMYK 値 | 元の CMYK 値をそのまま使用 |
| PDF | 広色域 RGB（Rec.2020）へ描画した結果 | 印刷プロファイルの色空間へ描画した結果 |

元データのプロファイルは埋め込みプロファイルを優先します。\
埋め込みがない場合は、RGB 画像に詳細設定の入力プロファイル（既定は sRGB）を、CMYK 画像に選択中の印刷プロファイルを割り当てます。

## 入力

| 形式 | 扱い |
| --- | --- |
| PNG、JPEG、TIFF | RGB と CMYK を元の値のまま読み込む。グレースケールは RGB として扱う |
| PSD | 統合画像のみを読み込む |
| PDF | 1 ページずつ描画する |

- アルファは白地に合成します。
- JPEG は EXIF の向きを反映します。
- 画素数が 1 億を超える画像と、アルファやスポットのチャンネルを持つ CMYK の PSD は読み込めません。

## PDF

PDF は OutputIntent を印刷プロファイルへ差し替えてから描画します。\
これにより DeviceCMYK の値がそのまま分版に残り、RGB の要素だけが印刷プロファイルへ変換されます。

- 変換は MuPDF が行い、相対的な色域を維持・黒点補正ありで固定です。（詳細設定のインテントは PDF に効きません）
- 元データを sRGB ではなく広色域 RGB へ描画するのは、CMYK の色を切り詰めずに比較の基準とするためです。
- オーバープリントは再現されません。
- 描画の解像度は 300dpi を上限とします。

## 変換

RGB 画像を印刷プロファイルへ変換する際の既定は「相対的な色域を維持」で、黒点補正を有効にします。\
どちらも詳細設定で変更することができます。

変換後は次の順で印刷再現を求めます。

1. 分版を絶対測色の Lab へ変換する
2. PP 加工がある場合は、加工の前後の測色値の差を加える
3. 紙色を反映する
4. 表示色空間へ変換する

紙色を反映した結果は、分版をプロファイルの絶対的な測色値のまま画面に出したものです。（Photoshop の校正設定で「紙色をシミュレート」を選んだ表示に当たる）\
反映しない場合も黒点補正は掛けず、印刷の黒を実際の濃さで表示します。

## 精度

- RGB 画像は 16bit の CMYK を経由し、変換を置き換える格子を細かくして変換します。\
  最適化を切った浮動小数点の変換との差は平均 ΔE00 0.02、最大 0.5 です。
- 印刷再現は Little CMS の校正用の変換（`cmsCreateProofingTransform`）と同じ色になります。（`tests/worker.test.ts`）
- 再現の正しさは印刷プロファイルが実際の印刷にどれだけ合っているかで決まります。\
  規格どおりの印刷でも、基準値からの許容差（ISO 12647-2 でベタの色に ΔE 5）の分は実物と差が出ます。

## 紙色

既定では印刷プロファイルが持つ用紙の白色点を画面に反映し、\
詳細設定で反映の有無を切り替えることが可能です。

特殊紙では指定した紙色を白色点の代わりに使い、この切り替えにかかわらず反映します。

## 色域外の判定

元データと印刷再現の色差 ΔE2000 が 5 を超える画素を色域外とします。

- 印刷再現には PP 加工を含め、紙色は含めません。
- 印刷の黒は画面の黒より明るいため、双方の最暗部を 0 に合わせた階調どうしで比べます。

判定結果は画像上の強調表示と、画像全体に占める割合の算出に使います。

## 画面への出力

Display P3 に対応した画面では P3 で、対応していない画面では sRGB で出力します。\
CMYK のシアンや緑には sRGB の外にある色があり、P3 対応の画面ではその色を表示することができます。

現時点でブラウザは利用者のモニター特性を取得できないため、\
表示される色はモニターによって異なります。

## 解像度

| 用途 | 長辺の上限 |
| --- | --- |
| 作業用画像 | 4096px |
| 画面表示 | 表示領域の実画素数（最大 2048px） |
| 再現画像の保存 | 4096px |
| 比較画像の保存 | 片側 2828px |

保存する画像の色空間は sRGB です。
