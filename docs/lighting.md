# 立体表示

照明の当たった紙を立体で表示し、光源による見え方・つや・反射の違いを確かめるための表示

## 色

照明は無彩色の光として描き、陰影・つや・映り込みだけを担わせます。\
光源の色は、目が慣れきれずに残る色かぶりとして扱います。

2D の再現画像は D50 の光に完全に慣れた見え方です。\
そのため、CAT16 の錐体応答ごとに次の倍率を基本色に掛けます。

```
D + (1 − D) × 光源の白 ÷ 画面の白
```

順応度 D は CIECAM16 の式で、照明の照度から求めます。（周囲は平均的、背景の反射率は 20%）

```
D = 1 − (1 / 3.6) × exp((−L_A − 42) / 92)、L_A = 0.2 × 照度 ÷ π
```

実装では、基本色に行列 `diag(1/c)·A` を掛け、すべての光の色を `c = A·(1, 1, 1)` にします。（`A` は上の倍率を作業色空間の線形 RGB に直した行列）\
こうすると、拡散反射は色かぶりを掛けた基本色に、鏡面反射は光の色になります。（`src/lib/lighting.ts`）

光の色を RGB のまま基本色に掛け合わせる方法は使いません。\
FOGRA51 の分光データで計算すると、この方法の誤差（ΔE00 の平均 5〜7）は、光源本来の色の変化（平均 3 前後）より大きくなるためです。

## 照明

| 照明 | 光 | 光源の色 | 照度の想定 | 順応度 D |
| --- | --- | --- | --- | --- |
| 日光 | 左上手前からの太陽と青空 | 昼光 6504K | 100,000 lx | 1.0 |
| 曇り | 空全体からの拡散光 | 昼光 6504K | 10,000 lx | 1.0 |
| 昼白色 | 手前上方の天井の面光源 2 枚 | 黒体 5000K | 500 lx | 0.875 |
| 電球色 | 左上手前からのスポットと暗い室内 | 黒体 2700K | 100 lx | 0.84 |

屋外では目が光源に慣れきるため、色かぶりは残りません。\
屋内では昼白色にわずかな、電球色にはっきりした暖かい色かぶりが残ります。

露出は照明ごとに調整し、正面を向いた紙の白が 2D の再現に近い明るさになるようにしています。\
画面の明るさには限りがあるため、トーンマッピング（Khronos PBR Neutral）で明るい所を圧縮します。

## つや

粗さは three.js の `roughness` で、光沢計の値（75° の光沢度）から換算した値です。

| 用紙 | 紙 | インキに覆われた所 |
| --- | --- | --- |
| コート紙 | 0.22 | 0.20 |
| マット紙 | 0.40 | 0.33 |
| 上質紙 | 0.55 | 0.55 |
| 特殊紙 | 0.60 | 0.60 |

- インキに覆われた面積率に応じて紙とインキの値の間を補い、インキの載った所だけ光る「差分光沢」を表します。
- オンデマンド（乾式トナー）は、インキ側の値を 0.32 以下にします。（トナーは紙より光る）
- インクジェットは、インキ側を紙と同じにします。
- PP 加工は透明な上塗りの層で表し、粗さはグロスが 0.10、マットが 0.40 です。
- 上質紙と特殊紙は、鏡面反射の強さを 0.6 倍にします。

値はすべて `src/lib/surface.ts` にあります。

## 紙

縦横比は画像から、厚さは用途の代表的な寸法から決めます。

| 用途 | 長辺 | 厚さ |
| --- | --- | --- |
| 名刺 | 91mm | 0.3mm |
| ポスター | 728mm（B2） | 0.15mm |
| チラシ | 297mm（A4） | 0.09mm |
| 冊子 | 210mm（A5） | 0.1mm |

表には 2D と同じ再現画像を、裏と縁には紙の色を使います。\
紙白の反映を切ると、紙を完全な白として照らします。

## 再現しないもの

- **分光特性による色の変化**：ICC プロファイルには D50 の光での色しかないため、インキや紙の分光特性で光源ごとに色の差が変わる現象（条件等色）は再現できません。\
  FOGRA51 の分光データでは、A 光源や電球色の LED で平均 ΔE00 3 前後、最大 7〜11 の変化があります。
- **蛍光増白剤**：紫外線の多い日光で紙が青白く光る効果は再現しません。
- **実際の明るさ**：日光の明るさやまぶしさは、画面の明るさの範囲に圧縮されます。
- **暖かい光への慣れの弱さ**：CIECAM16 の順応度は光源の色温度を考慮しないため、電球色の色かぶりは実際より小さく見積もられます。
- **紙以外の物**：置き場所や周囲の物は描きません。
