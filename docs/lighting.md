# 立体表示

照明の当たった紙を立体で表示し、光源による見え方・つや・反射の違いを確かめるための表示

## 色

照明は無彩色の光として描き、陰影・つや・映り込みだけを担わせます。\
光源の色は、目が慣れきれずに残る色かぶりとして扱います。

2D の再現画像は D50 の光に完全に慣れた見え方です。\
そのため、CAT16 の錐体応答ごとに次の倍率を基本色に掛けます。

```
D + (1 − D) × 光源の白 ÷ 画面の白
```

順応度 D は CIECAM16 の式で、照明の照度から求めます。（周囲は平均的、背景の反射率は 20%）

```
D = 1 − (1 / 3.6) × exp((−L_A − 42) / 92)、L_A = 0.2 × 照度 ÷ π
```

実装では、基本色に行列 `diag(1/c)·A` を掛け、すべての光の色を `c = A·(1, 1, 1)` にします。（`A` は上の倍率を作業色空間の線形 RGB に直した行列）\
こうすると、拡散反射は色かぶりを掛けた基本色に、鏡面反射は光の色になります。\
光の色は、画面に出せる範囲に収まるように最大の成分を 1 にします。（`src/lib/lighting.ts`）

光の色を RGB のまま基本色に掛け合わせる方法は使いません。\
FOGRA51 の分光データで計算すると、この方法の誤差（ΔE00 の平均 5〜7）は、光源本来の色の変化（平均 3 前後）より大きくなるためです。

## 照明

| 照明 | 光 | 光源の色 | 照度の想定 | 順応度 D |
| --- | --- | --- | --- | --- |
| 日光 | 高度 56° で左後方からの太陽と青空 | 昼光 6504K | 100,000 lx | 1.0 |
| 曇り | CIE の標準曇天空 | 昼光 6504K | 10,000 lx | 1.0 |
| 昼白色 | 1.2m 上、2m 手前の天井にある 0.6×1.2m の照明 2 枚 | 黒体 5000K | 500 lx | 0.875 |
| 電球色 | 1m 上、1.7m 手前にある 0.4m 角の照明 1 灯と暗い室内 | 黒体 2700K | 100 lx | 0.84 |

屋外では目が光源に慣れきるため、色かぶりは残りません。\
屋内では昼白色にわずかな、電球色にはっきりした暖かい色かぶりが残ります。

紙は実際の大きさで垂直に立て、照明は実際の距離に置きます。

- 日光は直射が全体の約 8 割で、残りは青空と日の当たった周囲からの光です。
- 曇りの空は天頂が地平線の 3 倍明るい分布です。（`L = Lz × (1 + 2 sin γ) ÷ 3`、γ は高度）
- 屋外の周囲は、高度 35〜50° より下を建物が占める街中を想定します。
- 昼白色は壁と天井からの間接光が全体の 3〜4 割、電球色は約 2 割です。
- 光源は、最初の向きで映り込みが紙のすぐ外に来る位置に置きます。（紙を少し回すとつやが見える）
- 紙の長辺が 0.3m を超える場合は、照明のむらが変わらないように光源を比例して遠ざけ、その分だけ明るくします。

配置と光の強さは `src/three/viewer.ts` にあります。

## 明るさ

最初の向きで紙の中央の拡散反射の白が 2D の再現の白になるように、全体の明るさを合わせます。\
倍率は照明と材質を切り替えるたびに、同じ向きの白い面と黒い面を描いて読み取り、その差（拡散反射）から求めます。

- 表面反射は拡散反射に加わるため、最初の向きでも黒は 2D の再現より明るくなります。（紙の白の 1〜3%）
- 紙を回すと、光の当たる角度に応じて明るさが変わります。
- 拡散反射の白までは明るさをそのまま出し、それより明るい照り返しだけを画面の白へ圧縮します。

色票 48 色を最初の向きで 2D の再現と比べた差は次のとおりです。（色かぶりを除く）

| 材質 | ΔE00 の平均 | 表面反射を除いた平均 |
| --- | --- | --- |
| コート紙 | 1.6〜2.5 | 0.5〜1.2 |
| マットコート紙 | 2.6〜3.4 | 1.0〜3.1 |
| 上質紙 | 1.0〜2.6 | 0.7〜1.8 |
| コート紙にグロス PP | 1.3〜2.6 | 0.2〜0.8 |
| コート紙にマット PP | 2.3〜3.8 | 1.0〜3.7 |

## つや

粗さは three.js の `roughness` で、光沢計の値（75° の光沢度）から換算した値です。

| 用紙 | 紙 | インキに覆われた所 |
| --- | --- | --- |
| コート紙 | 0.22 | 0.20 |
| マット紙 | 0.40 | 0.33 |
| 上質紙 | 0.55 | 0.55 |
| 特殊紙 | 0.60 | 0.60 |

- インキに覆われた面積率に応じて紙とインキの値の間を補い、インキの載った所だけ光る「差分光沢」を表します。
- オンデマンド（乾式トナー）は、インキ側の値を 0.32 以下にします。（トナーは紙より光る）
- インクジェットは、インキ側を紙と同じにします。
- PP 加工は透明な上塗りの層で表し、粗さはグロスが 0.10、マットが 0.40 です。\
  フィルムを貼ると紙やインキは空気に触れないため、表面で反射するのはフィルムだけにします。
- 表面の反射率は屈折率 1.5 の値（垂直で 4%）です。

測色値は 45° で照らして 0° で測った値で、粗い面で散った光の一部をすでに含んでいます。\
立体表示では表面反射を別に描くため、二重に数えないよう、その分を色から引きます。\
引く量は粗さから求めた反射率で、コート紙が 0.15%、マット紙とマット PP が 1.3%、上質紙が 2.5% です。\
マット PP の実測（FOGRA49）では黒の反射率が加工前より約 1.5% 高く、粗さ 0.40 から求めた値とほぼ一致します。

値はすべて `src/lib/surface.ts` にあります。

## 再現しないもの

- **分光特性による色の変化**：ICC プロファイルには D50 の光での色しかないため、インキや紙の分光特性で光源ごとに色の差が変わる現象（条件等色）は再現できません。\
  FOGRA51 の分光データでは、A 光源や電球色の LED で平均 ΔE00 3 前後、最大 7〜11 の変化があります。
- **蛍光増白剤**：紫外線の多い日光で紙が青白く光る効果は再現しません。
- **実際の明るさ**：日光の明るさやまぶしさは、画面の明るさの範囲に圧縮されます。
- **暖かい光への慣れの弱さ**：CIECAM16 の順応度は光源の色温度を考慮しないため、電球色の色かぶりは実際より小さく見積もられます。
- **実際の置き場所**：周囲は明るさの分布だけを決めた仮の環境で、置き場所の景色や周囲の物は映り込みません。
- **用紙ごとのつやの差**：粗さは用紙の種類ごとの代表値で、銘柄による差は反映しません。
