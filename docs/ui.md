# 画面

画面の構成と、各領域に置く内容

## 基準

スマホでの表示を基準とし、暗い無彩色の配色で画像の色の判断を妨げないようにします。

幅 900px 以上では、画像を左に、情報と設定を右に並べます。

## 構成

上から順に次の領域を並べます。

| 領域 | 内容 |
| --- | --- |
| ヘッダー | ファイル名（押すとファイルを開く）、PDF のページ切り替え、保存 |
| 画像 | 元データと印刷再現の比較 |
| 色値 | 読み取った点の RGB 値と CMYK 値 |
| タブ | 条件と詳細の切り替え、使用中の印刷プロファイル名、目安の表示 |
| 設定 | 選択中のタブの項目 |
| フッター | 色域外の割合と強調表示の切り替え、X で共有、言語の切り替え、ソースコード |

## 画像

1 枚の画像の上で境界線を動かし、元データと印刷再現を見比べます。\
画像を押すと、その点の色値を読み取ります。

ファイルを開く前は、ファイルを開くボタンとサンプルで試すボタンを表示します。\
ファイルは画面へのドロップでも開くことができます。

## 色値

RGB は元データの値、CMYK は分版の網点率です。\
CMYK 画像と PDF では RGB を表示しません。

## 設定

| タブ | 項目 |
| --- | --- |
| 条件 | 用途、印刷方式、用紙、PP 加工、印刷基準、紙色（特殊紙のみ）、印刷プロファイルの出どころ（選択肢が複数ある場合のみ） |
| 詳細 | レンダリングインテント、入力プロファイル、黒点補正、紙白の反映、ICC プロファイルの読み込み |

効果のない項目は無効にします。

- 印刷方式・用紙・印刷基準：ファイルの指定または読み込んだプロファイルを使用中
- レンダリングインテント・黒点補正：RGB 画像以外
- 入力プロファイル：RGB 画像以外、または埋め込みプロファイルのある画像

## 注記

- 標準プロファイルに基づかない条件では「目安」を表示し、押すと理由と ICC プロファイルの読み込みを案内します。
- モニターによって見え方が異なることを画面の下端に常時表示します。

## 保存

| 種類 | 内容 |
| --- | --- |
| 再現画像 | 印刷再現の見た目 |
| 比較画像 | 元データと印刷再現を左右に並べた画像 |

スマホでは作成の完了後にボタンを押して保存し、共有シートが使える環境では共有シートを開きます。

## 言語

日本語と英語に対応します。\
初回はブラウザの言語設定で選び、フッターで切り替えることが可能です。

## 設定の保存

条件と詳細の設定、言語、読み込んだ ICC プロファイルを端末に保存します。\
画像は保存しません。
